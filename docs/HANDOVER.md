# paarlwine.com — brand handover checklist

Use this when preparing the domain and the app for sale. Tick each line only after it is true.

## What a buyer receives

| Asset | Where it lives | Transfer method |
|-------|----------------|-----------------|
| Domain `paarlwine.com` | Registrar (Xneelo) | Registrar transfer / account push |
| WordPress site (OceanWP) | Xneelo hosting | Hosting account transfer or full backup and restore |
| App source code | GitHub repository | Repository transfer |
| App database and photos | Supabase project | Project transfer to the buyer's organisation |
| App hosting | Vercel project | Project transfer |
| Mailbox `hello@paarlwine.com` | Xneelo | Mailbox hand-over |
| Brand name "Terroir" and "Paarl Wine" | Not registered | See "Open items" |

## Not transferable: buyer sets up their own

- Anthropic API key (label scanner)
- Google OAuth client (Google sign-in)
- SMTP password (change it on hand-over)

## Before listing

- [ ] Every page on both sites reviewed for factual accuracy by a person (wine details, estate details, opening hours, links).
- [ ] Privacy policy and terms published on paarlwine.com and linked from the app footer. The app collects emails and photos,
      so a privacy policy covering South Africa's POPIA is needed.
- [ ] Estate listings: written permission from any estate named, or confirmation they are listed for free as the site says.
- [ ] Analytics (visitors, scans, sign-ups) set up, so a buyer can see real traffic. Without numbers, value rests on the name alone.
- [ ] Running costs written down (domain, hosting, Supabase, Vercel, Anthropic usage).
- [ ] Test accounts and test data removed from the database.

## Open items for the owner

- Trademark: neither "Terroir" nor "Paarl Wine" is registered. "Terroir" is a very common wine word, so a buyer may ask
  for the app to carry a more distinctive name. The domain is the main asset.
- Search ranking, traffic and revenue are the things buyers value most. This checklist makes the assets clean and transferable
  but cannot create those numbers.
